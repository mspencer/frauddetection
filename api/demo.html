Fraud Prediction API Test Client

  1. Copy a row from Kaggle's credit card fraud detection dataset: https://github.com/psundaravadivel/Credit-Card-Fraud-Detection/blob/main/CreditcardDataset.csv?plain=1
  2. Paste that row in the CSV text/plain Payload
  3. Click "Text Conversion" button. Obseve the python dictionary response in "CSV to Dictionary Response"
  4. Click "Fraud Prediction" button. Obseve the python dictionary response in "Fraud Prediction Response"
The API response will appear here after you click the Fraud Prediction button.
The API response will appear here after you click the Text Conversion button.
