Fraud Prediction API Test Client

  1. Copy a row from Kaggle's credit card fraud detection dataset: https://github.com/psundaravadivel/Credit-Card-Fraud-Detection/blob/main/CreditcardDataset.csv?plain=1
  2. Paste that row in the CSV payload
  3. Click "Send CSV to Dictionary Request"
  4. In the "Dictionary Response" copy only the dict object from the "data" array
  5. Paste in the "JSON Payload"
  6. Prediction can be seen in the "Fraud Prediction Response" box
